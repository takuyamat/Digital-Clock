# Digital-Clock（Python）

## 概要
Pythonのtkinterを活用して作成したデジタル時計のGUIアプリケーションです。

## 使用技術
- Python

## 主な機能
- 現在日時の表示
- 加賀地方の天気予報表示（気象庁API）
- 背景画像スライドショー
- 画面表示色の変更
- アラーム機能

## 工夫した点
- 背景画像が一定時間ごとに変更するようにした。また、変更時間のメニューで設定できるようにした。
- 色データをリストで格納することで、メニューから文字の色を変更できるようにした。
- os,winsoundでアラーム機能の制御ができるようにした。

## 今後の改善点
- 画面デザインを改善する
- 天気のAPIの改良（他の地域の天気も見れるように改修）
- 機能ごとにコードを分割する

## 実行方法
```bash
pip install -r requirements.txt
python main.py
```
